# Official Grilling Stage

This is not a second grilling protocol.

1. Read `official-skills.md` and load official `grill-with-docs` when glossary or ADR work
   is in scope; otherwise load official `grilling` and, when terms or decisions crystallize,
   official `domain-modeling`.
2. Follow the official interview until that skill's own exit is satisfied, including any
   shared-understanding confirmation it requires.
3. Persist accepted decisions, glossary updates, and ADRs. Copy durable excerpts into
   `docs/grillstorm/<goal-slug>/decisions.md` and the route's spec files.
4. Return to Grillstorm routing. Do not start implementation from this file.

Ask every currently independent decision in one numbered frontier round only because the
official grilling skill does. A question that depends on another open question belongs to a
later official round.

After launch, do not load this stage again.
