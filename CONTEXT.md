# myskills

Plugin development context for generating and executing project-local workflows. This glossary is the language of the system, not a spec for any one protocol file.

## Language

**Capability**:
A reusable methodology plus output contract for one kind of work, stored under `knowledge/capabilities/`. It is reference material, not a menu of nodes.
_Avoid_: skill, node, template

**Skill**:
An invocable operating procedure (`SKILL.md` or an equivalent entry such as `bootstrap.md`) that an agent follows to do a job.
_Avoid_: capability, protocol

**Node-spec**:
A disposable, project-local task brief for one workflow node, generated by bootstrap into the target project and safe to regenerate.
_Avoid_: skill, capability

**Protocol**:
A cross-node invariant: data-bus contracts, suppress rules, validators, expanders, and audit gates. It is not a step-by-step tutorial for the model.
_Avoid_: skill, capability, design spec

**Expander**:
An idempotent project-local script that may add or repair nodes after planning, without being a substitute for bootstrap's goal analysis.
_Avoid_: node injection, template

**Suppress rule**:
A detection-triggered prohibition on emitting a class of nodes (for example library-sdk omits demo-forge). Breaking it is a planning error, not a style choice.
_Avoid_: skip, omit, optional
