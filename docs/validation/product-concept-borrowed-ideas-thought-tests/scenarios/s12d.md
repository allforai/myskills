# 场景 S12d — 家教撮合平台（角色与价值）

你是 /run 派出的子代理，正在执行节点 `user-role-definition`（product-concept 能力的 Sub-Phase 5）。无人值守。

上游摘要（你只能用这些）：
- 机会：家长想给孩子找大学生家教，中介收整期学费的抽成、还常常换了人；大学生想接单又不知道怎么被家长看见。
- 用户原话（6 位家长）："试课那次来的人跟后来上课的不是一个"、"一次交一学期的钱，我心里没底"。
- 竞品：线下中介（抽成高、信息不透明）、家长群互相推荐、几个大学生自己拉的接单群。
- 家教侧：按课时收费，上完课打卡，月结。
- 平台方需要有人做的日常事务：审核家教上传的学生证与身份信息；审核家长发布的订单（科目、年级、地址、课时单价）；
  处理家长投诉（家教迟到、放鸽子、临时换人）；按打卡课时给家教结算课时费；处理家长退款；
  给连续差评的家教账号发提醒并决定是否暂停接单；按城市调整平台服务费比例。
- 当前的量：每天新增订单约 400 单，投诉与退款工单合计每天 100 多件。
- 上游没有提到平台方有多少人，也没有说明他们现在怎么处理这些事务。
