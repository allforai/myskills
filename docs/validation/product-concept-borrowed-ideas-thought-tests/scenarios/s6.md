# 场景 S6 — 会议室预订（破题 + 角色）

你是 /run 派出的子代理，项目很小，bootstrap 把 problem-discovery + user-role-definition 合并成了一个节点（能力文件 Composition Hints 的 Minimal 形态）。用户在线。

**任务**：按能力文件的要求写出 `problem-domain.json` 核心内容（问题本质 + 机会树骨架）和 `role-profiles.json` 中每个角色的 JTBD。不超过 35 行。
