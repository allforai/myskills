## Anonymous Meta-Skill Feedback

Category: blind-spot
Meta-skill version: unknown

### Failure Pattern

Declared repair node whose fix must edit exit artifacts owned by completed upstream nodes (not its QA node) stales those owners; the delivery measure then sees the gate withheld by non-QA nodes and records unmeasured_repair_delivery on every attempt, burning the whole budget without the QA ever rerunning. Repair loops need an adopt/republish step for upstream owners.

### Expected Behavior

The meta-skill should record or repair this class of workflow issue without exposing project-specific information.

### Suggested Fix

Update the relevant skill, bootstrap rule, validator, or orchestrator helper so future projects do not hit the same failure pattern.
