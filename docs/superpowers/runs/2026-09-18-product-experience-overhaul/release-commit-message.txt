## 升级影响

已经 bootstrap 过的**产品路线**项目升级后，下一次 `/run` 会被 `missing_experience_priority` 拦下：
旧 profile 里没有 `experience_priority`，需回到交互式 `/bootstrap` 补上。界面产品随后还会被要求补
体验方向、体验设计节点与 design / runtime 两阶段体验质量门。`local-change` 路线与没有 `task_route`
的遗留 profile 不受影响。
