## T02：测试判据修正，不是 skill 修复

原判据要求“具体推荐和保留/暂缓选项”。但已冻结的协议同时明确：“没有有价值的建议是有效结果”和“零建议则不给空选择题”。T02 判定两个改动都不值得，说明保留理由而不提问，符合协议，不能为了满足测试而制造无意义选择。

因此将测试判据修正为：有值得采纳的改动时给具体选择；无成立的简化建议时说明保留理由，不给空选择题、不强造减行收益。**只重判既有答卷，未另起受测运行；原判据文字和原输入摘要均保留。**
