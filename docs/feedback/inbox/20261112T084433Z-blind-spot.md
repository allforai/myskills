## Anonymous Meta-Skill Feedback

Category: blind-spot
Meta-skill version: unknown

### Failure Pattern

A node editing files inside its own declared parallel_write_scopes (shared README index) is detected as an unmapped 'uncertain' external change for sibling nodes whose whole-repo source snapshot includes those files; their evidence goes stale and a downstream node hard-fails on stale upstream mid-run. Declared sibling writes should not count as external change, or shared index files need a single owner.

### Expected Behavior

The meta-skill should record or repair this class of workflow issue without exposing project-specific information.

### Suggested Fix

Update the relevant skill, bootstrap rule, validator, or orchestrator helper so future projects do not hit the same failure pattern.
