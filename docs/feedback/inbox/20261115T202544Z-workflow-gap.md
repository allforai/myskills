## Anonymous Meta-Skill Feedback

Category: workflow-gap
Meta-skill version: 0.31.1-codex.1

### Failure Pattern

A successful executor CLI exit plus unchanged old passing artifacts can overwrite a worker blocked verdict and erase a pending correction. Require a current terminal attempt report, veto failure or unresolved blockers before serial and parallel acceptance, and prevent old proof from skipping pending repairs. Keep true repair delivery accounting separate from completion. Regression cases should include missing terminal report, completed-with-blockers, unchanged old proof, and failed-but-measured delivery.

### Expected Behavior

The meta-skill should record or repair this class of workflow issue without exposing project-specific information.

### Suggested Fix

Update the relevant skill, bootstrap rule, validator, or orchestrator helper so future projects do not hit the same failure pattern.
