## market-research 结论段（节点 `market-research` 产出）

**1. 对机会的判断：暂不确认（`unvalidated`），方向 A 与 B 都不升级为"已验证"。**
- 真正的行为证据（已发生的事）只落在**品类**层，不落在**本机会**层：付费商户 2.1 万家、99/159 元连续两年在售、两个模板社区各 1 万+下载，证明的是"小餐饮里有人为记账/对账类工具掏钱"；没有任何一条证明他们掏钱买的是"三处流水自动并表并出差异"这件具体的事。
- 400 余条含"对账"的评论只证明该词高频出现（显著性），不区分抱怨、功能缺失还是好评，不构成付费意愿；把它当需求强度是过度读数。
- "停运产品死于团队解散、公告写明付费用户数"是**反证"没人付费"**的证据，不是**证明本方向成立**的证据。把"不是否定"读成"是肯定"是本次最容易被方法正式度掩盖的错。
- 反面线索是自述（n=3，意愿而非行为），强度低，但它与该机会正面冲突（"差几块钱无所谓"、收银机自带报表已够），不能靠加权平均抹平，必须先解释。

**2. 竞品结论：类别成立，本机会的直接竞品未取证。** 99–159 元/月是已被市场检验的价位区间；但两家竞品是否做三源并表、是否只是开票/报税工具，未知。因此 `competitor-analysis.json` = partial（定位/定价/存活维度已填，直接竞品功能矩阵缺）；`errc-matrix.json` = incomplete，只注明缺哪条证据，不填 Create/Eliminate 占位值——宁缺不猜。

**3. 判别性问题与归属（须回退，而不是继续往下走）：**
- 2.1 万付费商户里多少为"多源对账"付费、多少为邻接工作（开票、报税）付费 → 归 `market-research` 自己，需一次竞品功能页+定价页取证。
- 老板对"差几块钱"的真实反应 → 归 `problem-discovery` / `concept-validation`，需要行为数据，再看访谈无增益。
- 方向 B"把差异推送给会计"是解决方案形态，且付款人可能是会计而非老板；现有付费证据全是"商户"，B 的付费假设未被任何证据覆盖。

**4. 给编排器与下游的记录：**
- 产物状态：`opportunity.status = unvalidated_with_counterevidence`；`competitor-analysis.json = partial`；`errc-matrix.json = incomplete`（附缺失清单）。
- 未解锁：`innovation-exploration` 不得把 A/B 当既定方向展开；`positioning`（Sub-Phase 8）若在此状态运行，`status` 只能是 `not_differentiated`，并写明缺的是"本机会的付费证据"，措辞无法补救。
- 解锁条件：至少一条针对本机会的行为证据（为多源对账付费/流失的真实数据），或行为数据推翻访谈反证。在此之前本节点结论是**证据不足**，不是"方向可行"。
