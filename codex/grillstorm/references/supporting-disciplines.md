# Conditional Supporting Disciplines

Load the matching official skill from `official-skills.md` when its trigger is present.
This file is not a second protocol.

| Trigger | Official skill |
|---|---|
| External fact is an unsettled prerequisite | `research` |
| A design question needs a throwaway artifact | `prototype` |
| Module depth, interface, or seam placement is itself in question | `codebase-design` |
| An actual merge or rebase conflict exists | `resolving-merge-conflicts` |

Keep grilling or planning independent branches moving while official `research` runs when
the host supports background work. Fold a validated prototype decision into the specs and
keep prototype code off the main delivery branch.
