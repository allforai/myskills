# 场景 S5a — 无人做过的品类（概念验证）

你是 /run 派出的子代理，正在执行节点 `concept-crystallization`（product-concept 能力的 Sub-Phase 9–10）。无人值守。

上游摘要（你只能用这些）：
- 机会：独居老人白天在家跌倒后，家属要等几小时才知道；现有方案是穿戴式按钮（老人经常不戴）和摄像头（家属觉得侵犯隐私，装了一半就关）。
- 用户原话（三位家属访谈）："我妈肯定不戴手表"、"摄像头她和我都别扭"、"出事的时候能早知道就行"。
- 竞品：没有直接替代。市场里只有穿戴设备、家用摄像头、以及"每天打一次电话"这种人工流程。没有一家做这个形态。
- 这类需求没有可比销售数据，没有公开的购买行为记录；三位访谈对象都没有买过任何类似产品。
- 技术侧：毫米波雷达模组可以做到不接触、不拍画面地判断跌倒，但目前只有开发板，没有量产模块，误报率数据缺失。
- 约束：家属愿意付月费（访谈里说了三次"一个月几十块可以"），但没人见过账单；老人本人没有表达过意愿。

**任务**：按能力文件的要求产出这个概念的假设登记与验证计划（哪些假设、怎么验证、多久、什么结果会让你改变决定），以及你认为本节点要留给编排器或后续节点的记录。不超过 30 行。
