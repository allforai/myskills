# Recover historical authorizations only from attributable evidence

The user accepted Q9 in the grill-with-docs session: historical authorization accounting may be reconstructed only from complete evidence that uniquely identifies the prior authorizations, preserving its provenance. Incomplete or ambiguous evidence leaves the existing run blocked; absence of records is not proof of unused budget.

Starting a separate new run requires explicit user confirmation and must not silently reset the old run's accounting. This trades seamless legacy continuation for trustworthy budget enforcement and preserves the old run's history rather than rewriting uncertainty as a clean start.
