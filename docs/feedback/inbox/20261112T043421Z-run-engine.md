## Anonymous Meta-Skill Feedback

Category: run-engine
Meta-skill version: unknown

### Failure Pattern

0.29.0: (1) a declared design repair node has no write scope over the producer specs it must fix, so every budgeted dispatch ends in unmeasured_repair_delivery and the loop only burns budget; the engine keeps dispatching against identical inputs. (2) During /run a node may register a read of a completed node that is not in its hard_blocked_by; nothing objects at read time, but the next readiness check reports dependency_outside_graph and requires interactive bootstrap, so the run cannot resume after a diagnosis reset. Suggest rejecting or warning at read registration, or letting readiness accept reads of already-completed producers.

### Expected Behavior

The meta-skill should record or repair this class of workflow issue without exposing project-specific information.

### Suggested Fix

Update the relevant skill, bootstrap rule, validator, or orchestrator helper so future projects do not hit the same failure pattern.
