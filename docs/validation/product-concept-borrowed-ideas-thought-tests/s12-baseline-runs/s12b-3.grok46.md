## Producer-side closure check
- 事故照片：R2 生产 → R1 消费
- 处理意见/责任比例/赔付金额：R1 生产（人拍板）→ R2 消费进度与结果；打款由保险公司执行，非本产品
- 维修单：R1 消费，生产者上游未给，不新建修理厂角色
- 天气与历史报案：R1 消费，生产者上游未给，不新建数据角色
- 谁运营：开通账号/配置规则/值守工作台的人上游未给，不编造管理员；付费与组织边界在保险公司
